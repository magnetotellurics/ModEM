# Cartesian-ModEM sanity check of `G` and the `EGBERTKELBERT2012_MODEM` preset (2026-07-27)

**Why:** the spherical ModEM runs used elsewhere (`Mod3DMT_SP2_SPH`) require
`-DBUILD_SPHERICAL -DFORCE_SPHERICAL`, bypassing a guard that warns *"The Spherical Version is
experimental and will not work with traditional MT source setup"* (`ModEM/CMakeLists.txt:76-82`) —
and the internal `COMPUTE_BC` path IS that traditional (WS/REBOCC per-column) source setup. Cartesian
ModEM, by contrast, is trusted and accurate. This check re-runs the `G` / normalization analysis
against Cartesian ModEM to confirm the framework doesn't depend on the experimental spherical BC.

**Model:** `Halfspace.rho` (generated by `make_halfspace_rho.sh`, so it need not be committed) — a Cartesian
48×68×44 grid, uniform ρ=100 Ω·m halfspace, with the same air setup as the spherical runs
(`Halfspace.fwd`: 12 air layers, 1000 km top, BICG). global1d run on the same ρ=100 halfspace
(`halfspace.prm`, all layers log₁₀ρ=2), USA grid, fake pole `(0,90)`, default `EGBERTKELBERT2012_MODEM`
preset.

**Everything is self-contained in this directory** except the two compiled binaries. Just run the
driver (from a WSL shell), then the analysis:

```bash
bash run_cartesian_sanity.sh     # -> out_cart.esoln + hs.*.esoln (edit ModEM/FWD1D paths at top)
python analyze_cartesian.py      # the analysis (numpy+scipy)
```

which is equivalent to:

```bash
# Cartesian ModEM (trusted) -- all inputs local to this directory:
<MODEM_CART> -F Halfspace.rho halfspace_template.dat out_cart.dat out_cart.esoln Halfspace.fwd
# global1d halfspace, default normalized preset (run from the repo root):
<FWD1D> testing/test_vs_modem_1D/halfspace.prm testing/test_vs_modem_1D/p10_halfspace.prm \
      MTsource/USA.0.25x0.25.grd testing/test_vs_modem_1D/hs 0 90
```

## Result 1 — the air-column mechanism (the heart of `G`), analytic vs Cartesian ModEM

`G`'s derivation rests on ModEM's surface field being set by the air-column thickness:
`E_ModEM(surface) = Z_e/(Z_e − iωμ₀·d_air)`. Checked directly against Cartesian ModEM's `.esoln`,
with the analytic halfspace impedance `Z_e = −iωμ₀/√(−iωμ₀σ)` (the `e^{−iωt}` root) and
`d_air = 999.97 km` (sum of the 12 air layers):

| `T` (s) | `|E_ModEM/E_pred|` | phase |
|---|---|---|
| 3.98 | 0.998 | +0.0° |
| 15.85 | 0.998 | +0.0° |
| 63.10 | 0.998 | +0.0° |
| 251 | 0.999 | +0.0° |
| 1000 | 0.997 | −0.1° |
| 3981 | 0.994 | −0.0° |

**Matches to 0.2–0.6%, ±0.1°, at every period** — the air-column mechanism is confirmed on trusted
Cartesian ModEM to sub-percent (and cleanly at all periods, unlike the spherical build).

## Result 2 — the full preset vs Cartesian ModEM

Surface `Ey` (V/m) at the equator, and `r = E_global1d,normalized / E_ModEM,cartesian`. These are
**reference values** for the ρ=100 Ω·m halfspace (USA `0.25×0.25` grid for global1d, `Halfspace.rho`
for Cartesian ModEM, both with the 12-layer / 1000 km air of `Halfspace.fwd`), printed by
`analyze_cartesian.py` — future runs should reproduce them:

| `T` (s) | `E_global1d,normalized` (Re, Im) | `E_ModEM,cartesian` (Re, Im) | `|r|` | `arg r` |
|---|---|---|---|---|
| 3.98   | `+5.02054e-03 +5.01364e-03` | `+5.00977e-03 +4.96092e-03` | **1.006** | **+0.2°** |
| 15.85  | `+1.00183e-02 +9.98776e-03` | `+9.99510e-03 +9.79991e-03` | 1.011 | +0.5° |
| 63.10  | `+1.99901e-02 +1.98656e-02` | `+1.99291e-02 +1.91681e-02` | 1.019 | +0.9° |
| 251.19 | `+3.98865e-02 +3.93881e-02` | `+3.97357e-02 +3.67643e-02` | 1.036 | +1.9° |
| 1000   | `+7.95850e-02 +7.75976e-02` | `+7.86225e-02 +6.75204e-02` | 1.073 | +3.6° |
| 3981   | `+1.58664e-01 +1.50446e-01` | `+1.52230e-01 +1.15216e-01` | 1.145 | +6.4° |

(Cartesian ModEM is laterally uniform to 0.00%, so its value is the lateral mean; the global1d value
is at its `sinθ=1` fake equator. Both are the raw internal `e^{-iωt}` field in V/m for a unit source.)

- **Short period: `|r|=1.006`, `+0.2°` — essentially perfect.** In the flat-earth limit (thin skin
  depth) global1d (spherical) → Cartesian, and `G = (3/2)√(3/4π)·d_air` is exact. This also confirms
  the `(3/2)=(2−Q₁)` factor: at short period a conductor looks "perfect" (`Q₁→½`).
- **The residual grows monotonically and cleanly with period** (`|r|` 1.006→1.145, arg +0.2°→+6.4°).
  This is the **genuine flat-vs-spherical difference**: at long period the field penetrates deeper,
  Earth's curvature matters, and the fully-spherical global1d gives a larger surface field than the
  flat Cartesian plane wave. global1d is the more accurate solution here.
- **Cartesian ModEM is laterally uniform to 0.00%** (vs the spherical build's ~1.5%), so there is no
  lateral-sampling ambiguity at all.

## Conclusion

The `iωμ₀·G` normalization and its air-geometry derivation are **validated against trusted Cartesian
ModEM**: the air-column mechanism to sub-percent at all periods, and the full preset to `0.6%` /
`0.2°` in the flat limit. The residual is unambiguously the **flat-vs-spherical** physics (clean,
monotonic, → 0 at short period), **not** an artifact of ModEM's experimental spherical BC. This both
confirms the framework and re-establishes that global1d is the more accurate fully-spherical
solution.

Scripts: `analyze_cartesian.py` (this directory).
